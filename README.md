# 💖 M❤️M — ذكرياتنا

تطبيق ويب رومانسي لعرض ذكرياتكم وصوركم الخاصة بأجمل شكل:
شاشة بداية بأسماء تتساقط في الخلفية (مزن، محمد، وتيني، نبضي) مع قلوب متطايرة،
خط زمني لحكايتكم، **ألبومات صور رومانسية** (بدايتنا، ليالي أبريل، سهرة أفلامنا، يومنا الكبير، لحظات سناب)،
معرض صور بنمط "بولارويد"، رسالة حب داخل ظرف، وأغنيتكما تُشغَّل تلقائياً فور فتح التطبيق 🎵

## 🚀 التشغيل

ببساطة افتح ملف `index.html` في المتصفح، أو شغّل أي خادم ملفات ثابتة:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

> 🎵 **الموسيقى**: الأغنية تعمل تلقائياً فور فتح التطبيق. بعض المتصفحات تمنع
> التشغيل التلقائي للصوت — في هذه الحالة تبدأ الأغنية مع أول نقرة أو تمرير في أي مكان.

## 📸 الصور والأيقونة

صوركما الخاصة موجودة في مجلد `photos/` (49 صورة) بأسماء `memory-01.jpg` … `memory-49.jpg`،
مع نسخ مصغّرة في `photos/thumbs/` تُستخدم للعرض السريع، بينما تفتح الصورة الأصلية
بدقة كاملة عند الضغط عليها في العارض الكبير.

**أيقونة التطبيق** 🖼️: صُنعت من أفضل صوركما (memory-20 — أعلى الصور وضوحاً) بإطار ذهبي
رومانسي وزوايا دائرية، وهي موجودة في مجلد `icon/` وتُستخدم كأيقونة للمتصفح
وعند إضافة التطبيق لشاشة الهاتف. لتغييرها: استبدل `photos/memory-20.jpg` بصورة أخرى
وأعد توليد الأيقونات، أو أخبرني وسأفعلها لك.

أغنيتكما موجودة في `audio/our-song.mp3` وتُشغّل تلقائياً فور فتح التطبيق
(أو عبر زر 🎵 أسفل الشاشة).

## ✏️ تخصيص التطبيق

كل البيانات في ملف واحد سهل: **`js/data.js`**

| ماذا تريد أن تغيّر؟ | كيف تفعل ذلك؟ |
|---|---|
| أسماءكما | عدّل `herName` و `hisName` في `APP_CONFIG` |
| الأسماء المتساقطة في الخلفية | عدّل مصفوفة `FALLING_NAMES` في `js/main.js` |
| تاريخ بداية الحكاية (لعدّاد الأيام) | عدّل `startDate` بصيغة `سنة-شهر-يوم` |
| نصّ كل ذكرة (العنوان، التاريخ، المكان، القصة) | عدّل الحقول في كل عنصر من مصفوفة `memories` |
| ترتيب الذكريات | أعد ترتيب العناصر في `memories` |
| إضافة ذكريات جديدة | أضف صورة في `photos/` باسم جديد + عنصراً في `memories` |
| الألبومات (تقسيم الصور) | عدّل مصفوفة `albums` في `js/data.js` (photos = أرقام الصور) |
| نص رسالة الحب | عدّل `letter-body` في `index.html` |
| الأغنية | استبدل `audio/our-song.mp3` بأغنيتكما |
| أيقونة التطبيق | استبدل `photos/memory-20.jpg` وأعد توليد `icon/` (أو أخبرني) |

## 📱 التحويل إلى تطبيق أندرويد (APK)

التطبيق **جاهز للتحويل** — هو تطبيق ويب ثابت بكل ملفاته محلية (صور، أغنية، أيقونات)،
ومع `manifest.webmanifest` و `capacitor.config.json` المرفقين، يمكن تحويله إلى APK بثلاث طرق:

### الطريقة 1 (الأسهل — بدون أي برمجة) 🌟
استخدم موقعاً يحوّل ملفات الويب إلى APK مثل:
- **WebIntoApp** — webintoapp.com (ارفع ملف `index.html` + المجلدات، أو رابطاً)
- **Website 2 APK** — websiteseotools.com أو appsgeyser.com

ارفع ملفات المشروع (أو الرابط إن نشرت التطبيق على GitHub Pages) وستحصل على APK جاهز.

### الطريقة 2 (الاحترافية — Capacitor)
يتطلب تثبيت [Node.js](https://nodejs.org) و[Android Studio](https://developer.android.com/studio):

```bash
npm install @capacitor/core @capacitor/cli
npx cap add android
npx cap sync android
npx cap open android   # ثم: Build → Build APK
```

سيُنشئ مجلد `android/` وتستطيع بناء APK من Android Studio مباشرة.

### الطريقة 3 (بدون APK — تثبيت من المتصفح)
افتح التطبيق في كروم على هاتف أندرويد → القائمة ⋮ → **إضافة إلى الشاشة الرئيسية**.
سيُثبَّت كتطبيق مستقل (بفضل `manifest.webmanifest` والأيقونات) بدون حاجة لأي تحويل.

> 💡 ملاحظة: الموسيقى تعمل تلقائياً في تطبيق الأندرويد (WebView يسمح بالتشغيل التلقائي).

## 🗂️ بنية المشروع

```
├── index.html                ← الصفحة الرئيسية (الهيكل + رسالة الحب + مشغل الموسيقى)
├── manifest.webmanifest      ← ملف PWA (لتثبيت التطبيق + الأيقونات)
├── capacitor.config.json     ← إعداد تحويل APK عبر Capacitor
├── package.json              ← أوامر Capacitor المساعدة
├── css/style.css             ← التصميم الرومانسي الكامل
├── js/data.js                ← ⭐ البيانات: 49 ذكرة مع الصور والتواريخ والألبومات
├── js/main.js                ← منطق التطبيق: القلوب، الخط الزمني، المعرض، الألبومات، الموسيقى
├── photos/                   ← صوركما الأصلية (memory-01.jpg … memory-49.jpg)
│   └── thumbs/               ← نسخ مصغّرة للعرض السريع
├── icon/                     ← أيقونات التطبيق (من أجمل صورتكما)
└── audio/our-song.mp3        ← أغنيتكما
```
