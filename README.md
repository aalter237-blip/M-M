# 💖 M❤️M — ذكرياتنا

تطبيق ويب رومانسي لعرض ذكرياتكم وصوركم الخاصة بأجمل شكل: شاشة بداية بأسماء تتساقط في الخلفية
(مزن، محمد، وتيني، نبضي) مع قلوب متطايرة، خط زمني لحكايتكم، معرض صور بنمط "بولارويد"،
رسالة حب داخل ظرف، وأغنيتكما كموسيقى خلفية.

## 🚀 التشغيل

ببساطة افتح ملف `index.html` في المتصفح، أو شغّل أي خادم ملفات ثابتة:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## 📸 الصور

صوركما الخاصة موجودة في مجلد `photos/` (49 صورة) بأسماء `memory-01.jpg` … `memory-49.jpg`،
مع نسخ مصغّرة في `photos/thumbs/` تُستخدم للعرض السريع، بينما تفتح الصورة الأصلية
بدقة كاملة عند الضغط عليها في العارض الكبير.

أغنيتكما موجودة في `audio/our-song.mp3` وتُشغّل تلقائياً بعد الضغط على «ابدأ رحلتنا»
(أو عبر زر 🎵 أسفل الشاشة).

## ✏️ تخصيص التطبيق

كل البيانات في ملف واحد سهل: **`js/data.js`**

| ماذا تريد أن تغيّر؟ | كيف تفعل ذلك؟ |
|---|---|
| أسماءكما | عدّل `herName` و `hisName` في `APP_CONFIG` |
| الأسماء المتساقطة في الخلفية | عدّل مصفوفة `FALLING_NAMES` في `js/main.js` |
| تاريخ بداية الحكاية (لعدّاد الأيام) | عدّل `startDate` بصيغة `سنة-شهر-يوم` |
| نصّ كل ذكرة (العنوان، التاريخ، المكان، القصة) | عدّل الحقول في كل عنصر من مصفوفة `memories` |
| ترتيب الذكريات | أعد ترتيب العناصر في `memories` |
| إضافة ذكريات جديدة | أضف صورة في `photos/` باسم جديد + عنصراً في `memories` |
| نص رسالة الحب | عدّل `letter-body` في `index.html` |
| الأغنية | استبدل `audio/our-song.mp3` بأغنيتكما |

## 🗂️ بنية المشروع

```
├── index.html        ← الصفحة الرئيسية (الهيكل + رسالة الحب + مشغل الموسيقى)
├── css/style.css     ← التصميم الرومانسي الكامل
├── js/data.js        ← ⭐ البيانات: 49 ذكرة مع الصور والتواريخ
├── js/main.js        ← منطق التطبيق: القلوب، الخط الزمني، المعرض، الرسالة، الموسيقى
├── photos/           ← صوركما الأصلية (memory-01.jpg … memory-49.jpg)
│   └── thumbs/       ← نسخ مصغّرة للعرض السريع
└── audio/our-song.mp3 ← أغنيتكما
```

## 🎨 المزايا

- ✨ أسماء متساقطة في خلفية التطبيق (مزن، محمد، وتيني، نبضي) + قلوب متطايرة وحركات ناعمة عند التمرير
- 💌 خط زمني رومانسي متناوب بحكايتكما
- 📸 معرض 49 صورة بولارويد مع عارض (Lightbox): الصورة الأصلية بدقة كاملة، وتنقّل بالأسهم أو اللمس
- 🎵 موسيقى خلفية (أغنيتكما) مع زر تحكم أنيق ومؤشر صوت متحرك
- 🌹 رسالة حب داخل ظرف بختم أحمر — اضغط على الختم لفتحها
- ⏳ عدّاد "أيام من الحب" يحسب تلقائياً منذ تاريخ بدايتكما
- 📱 متجاوب بالكامل مع الجوال والعربية (RTL)
